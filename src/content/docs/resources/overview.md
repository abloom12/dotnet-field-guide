A curated collection of resources for learning and working with the .NET stack. This list should stay selective: each entry should explain why it is worth using rather than becoming a general link dump.

## Official documentation

- [.NET documentation](https://learn.microsoft.com/dotnet/) — the main reference for the .NET platform, SDK, runtime, and libraries.
- [C# documentation](https://learn.microsoft.com/dotnet/csharp/) — the language guide and reference.
- [ASP.NET Core documentation](https://learn.microsoft.com/aspnet/core/) — guidance for building web applications and APIs.
- [Blazor documentation](https://learn.microsoft.com/aspnet/core/blazor/) — guidance for Blazor applications and components.
