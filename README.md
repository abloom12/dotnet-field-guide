# .NET Field Guide

A practical reference for C#, .NET, ASP.NET Core, Blazor, and application design.

## Run locally

### Prerequisites

- [Node.js](https://nodejs.org/) 22.12.0 or newer
- [pnpm](https://pnpm.io/installation/)

### Setup

```bash
git clone https://github.com/abloom12/dotnet-field-guide.git
cd dotnet-field-guide
pnpm install
pnpm astro dev --background
```

Open [http://localhost:4321](http://localhost:4321).

### Development server commands

```bash
pnpm astro dev status       # Check server status
pnpm astro dev logs --follow # Follow server logs
pnpm astro dev stop         # Stop the server
```
